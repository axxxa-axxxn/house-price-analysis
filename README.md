# 🏡 House Price Analysis

A complete **Exploratory Data Analysis (EDA)** project using the California Housing dataset from Kaggle.

This project demonstrates the complete data analysis workflow including data loading, dataset inspection, data cleaning, feature engineering, statistical analysis, visualization, outlier detection, and report generation using **Python, Pandas, Matplotlib, and Seaborn**.

---

## 📌 Dataset

**Dataset Name:** California Housing Prices

**Source:** Kaggle

### Dataset Features

| Feature | Description |
|----------|-------------|
| longitude | Longitude coordinate |
| latitude | Latitude coordinate |
| housing_median_age | Median age of houses |
| total_rooms | Total number of rooms |
| total_bedrooms | Total number of bedrooms |
| population | Population in the area |
| households | Number of households |
| median_income | Median income of residents |
| ocean_proximity | Distance from the ocean |
| median_house_value | Median house value |

# 🚀 Features

This project includes the following EDA tasks:

- Load the dataset
- Inspect the dataset
- Analyze missing values
- Remove duplicate records
- Clean the data
- Create new features
- Filter and sort data
- Perform GroupBy analysis
- Generate descriptive statistics
- Perform correlation analysis
- Detect outliers using the IQR method
- Create histograms
- Create scatter plots
- Create bar charts
- Generate a correlation heatmap
- Generate a pairplot
- Create a summary report

# ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/axxxa-axxxn/house-price-analysis.git
```

### 2. Open the project folder

```bash
cd House_Price_Analysis
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Run the project

```bash
python main.py
```
